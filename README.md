# Taskflow — Modern To-Do App

A sleek, dark-themed to-do application built with vanilla HTML, CSS, and JavaScript.

## Features

- ✅ Add, complete, and delete tasks
- 🏷️ Categorize tasks (Personal, Work, Health, Learning)
- 🎯 Set priority levels (Low, Medium, High)
- 🔍 Filter by All / Active / Done
- 💾 Persistent storage via `localStorage`
- ✨ Smooth animations and glassmorphism design
- 📱 Fully responsive

## Getting Started

Simply open `index.html` in your browser — no build tools needed.

```bash
open index.html
```

## Tech Stack

- HTML5
- CSS3 (custom properties, animations, backdrop-filter)
- Vanilla JavaScript (ES6+)
